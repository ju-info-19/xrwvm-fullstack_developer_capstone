# xrwvm-fullstack_developer_capstone - Cars Dealership

## Nom du projet
**xrwvm-fullstack_developer_capstone**

## Description
Application web complète pour un concessionnaire automobile national.

## Technologies
- Backend: Django, Django REST Framework
- Frontend: React.js
- Base de données: SQLite
- Déploiement: IBM Cloud Code Engine
- CI/CD: GitHub Actions

## Installation
```bash
git clone https://github.com/ju-info-19/xrwvm-fullstack_developer_capstone.git
cd xrwvm-fullstack_developer_capstone
pip install -r requirements.txt
python manage.py runserver
